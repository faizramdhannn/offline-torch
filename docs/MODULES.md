# Peta modul: menu → file → API → data → izin

Pendamping [CLAUDE.md](../CLAUDE.md). **Perbarui tabel ini setiap menambah/mengubah menu.**
Izin = kunci di `PERMISSION_KEYS` (`lib/users.ts`); penegakan di server ada di `RULES` (`lib/authz.ts`) — tabel ini hanya ringkasan, **sumber kebenarannya kode**.
`sheet:` = nama sheet Google Sheets (spreadsheet dari env `SPREADSHEET_*`), `neon:` = tabel Neon.

Server menentukan nama/kategori/harga item dari master (bukan dari klien); harga satuan tiap item default dari master tetapi **boleh diubah di form** (disimpan sebagai `item_price`); **diskon (%) per item** di form (kolom Disk %, plus pintasan "Diskon semua item") → `item_net` = harga × (1 − diskon%) per item, tabel menampilkan Harga (gross) dan Net, pesan WA menampilkan Diskon & Harga net, HP disimpan `62…`, **Reason Buy → Sales Order wajib**, wajib salah satu Reason Buy / Not Buy. `source_store`: akun toko dikunci ke namanya sendiri (server), Bulk All memilih dari daftar toko. Edit = tambah baris baru dulu lalu hapus baris lama; hapus = semua baris id itu. Data 120 hari terakhir (`?all=1` = semua riwayat). **Data awal (impor 11 Nov 2026)** dari obrolan WhatsApp "SEMANGAT CARI BULK ORDER" + pesanan Shopify 2026; definisi bulk = **satu kode item > 5 pcs** (bukan total pesanan), hanya item bulk yang disimpan; `created_by` = `system`. **Tombol "Kirim WA ke toko"** (input yang terbeli; admin ke nomor toko mana pun, akun toko ke nomor tokonya sendiri): membuka `wa.me` ke nomor WA profil toko dengan pesan format grup bulk (`buildBulkWaMessage` di `lib/bulkOrder.ts`; tanpa API/biaya). **Tab Report (khusus Bulk All)**: `components/bulk/BulkReport.tsx` + `buildBulkReport` di `lib/bulkOrder.ts` — KPI (input, customer unik, qty, nilai, closing rate, rata-rata/input), tren harian/mingguan, per toko, top 10 produk, donut Reason Buy / Not Buy / Kategori, customer terbesar; filter periode & toko; grafik recharts |

## Cron & otomatisasi
| Apa | Di mana | Catatan |
|---|---|---|
| Refresh PDF katalog | GitHub Actions `.github/workflows/catalog-refresh.yml` (utama), cron Vercel `/api/cron/catalog-refresh` 03:00 UTC (cadangan) | Jalankan `scripts/generate-catalogs.ts`; unggah ke Vercel Blob |
| Backup user | cron Vercel `/api/cron/users-backup` 20:30 UTC | Neon `app_users_backup` |
| Webhook Ably | `POST /api/realtime/webhook?s=<REALTIME_WEBHOOK_SECRET>` | Riwayat online/offline + peringatan |
